# AI Atlas · AI 系统地图

一句话：**不写课程，只画地图。** 每个概念回答四件事——从哪来、现在怎么用、还用不用、被谁替代。

**现在的样子**：https://logic77lhl.github.io/ai-atlas/ ——59 个概念、9 个领域、116 条深链、两种看法（地图 / 史书），单文件无依赖、可离线，进度存在浏览器本地，可选私有 Gist 跨设备同步。

## 两种看法

同一份数据，两个视图：

- **地图**：按领域分层，回答「它站在哪一层、依赖谁」
- **史书**：按年份编年（1986 — 2024），回答「它哪年进来、那时是什么水平」

年份是概念成形的时间，不是它今天的状态。带 `~` 的是估计——工程实践类没有单一论文可依，只能定到年。

## 五个动作

1. **看依赖图**：6 层，从上到下回答「谁依赖谁」（可折叠）
2. **切视图**：地图看结构，史书看时间
3. **筛状态**：标准 / 主流 / 过渡 / 衰退 / 历史 / 争议 / 未掌握
4. **点开一条**：前身、现在、边界、深链
5. **标记**：想学 / 看懂 / 已掌握

搜索会同时匹配中文名、英文名、三行正文和年份。

## 这不是什么

- 不是教程。不讲解原理推导，不复制别人的课文。
- 不是链接合集。每条链接都要能回答一个具体问题。
- 不是 hf-quest 的扩展。它是独立项目，hf-quest 只作为「工具线」被引用。

## 这是什么

- 9 个领域，59 个概念（硬上限 60）
- 6 层依赖图：基础 → 模型 → 训练 → 推理/检索 → Agent/评估 → 工程/边界
- 史书视图：按年份编年，分 7 段，每段写清「这段时间在解决什么问题」
- 每个概念 4 行：前身 / 现在 / 状态 / 边界，每条带「最后核对」月份
- 深链指向论文、GitHub 实现、官方文档
- 进度只记「想学 / 看懂 / 已掌握」，不记课时
- 状态筛选、领域跳转、全文搜索、导出 / 导入 / 清空
- 私有 Gist 同步：每个概念按修改时间取新，冲突不覆盖

## 同步怎么用

1. GitHub → Settings → Developer settings → Personal access tokens → **Tokens (classic)** → 只勾 `gist`
2. 点页脚「同步」→ 粘 token → 点「创建新存档」，拿到 Gist ID
3. 另一台电脑打开同一网址，粘同一个 token + Gist ID → 「立即双向同步」

token 只存在这台电脑的浏览器本地存储里，不进页面、不进导出文件。改完标记 2.5 秒后自动推送，打开页面自动拉取。用完可以在同一个弹层点「清除」。

## 数据模型

数据就在 `index.html` 的 `DATA` 数组里，一条长这样：

```js
{ id:"kvcache", zh:"KV 缓存", en:"KV cache", d:"inference", s:"standard", v:"2026-10",
  b:"每生成一个 token 都要重算整个历史",          // 前身：它替代了什么
  n:"缓存 K/V，用显存换速度",                    // 现在：实际怎么用
  e:"长上下文显存吃紧，才有 GQA / 量化 KV",       // 边界：什么时候不该用
  l:[["PagedAttention","https://arxiv.org/abs/2309.06180"],
     ["Databricks：推理性能工程","https://..."] ] }
```

年份单独放在 `YEAR` 表里（`id -> "2017-06"`，`~` 前缀表示估计），启动时挂到每条概念上。这样改年份不用动正文。

`CONCEPTS.md` 由这份数据生成，两边永远一致。**改内容只改 `index.html`**，然后重跑生成脚本。

## 已知限制

- 本机网络打不开 `huggingface.co`、`lmarena.ai`、`platform.openai.com`、`copyright.gov`、`docs.anthropic.com`，所以深链一律避开这些域名，改用论文 / GitHub / 可达的官方文档。
- 状态是判断，不是事实。每条带日期；「过期变灰」还没做，等 M3。
- 年份是判断，也不是事实。有论文的精确到月，工程实践类只能估到年（13 条带 `~`）。
- 时间轴止于 2024。2025—2026 没有新条目，不是没有变化，是变化还没沉淀成稳定概念。
- Gist 同步是整档覆盖写入，没有历史版本；同一概念在两台机器上同时改，按时间戳取新，输的那次改动会丢。
- 不覆盖语音、推荐系统、强化学习理论、世界模型——为守住「一张屏」的体量。

## 和 hf-quest 的关系

独立仓库、独立进度、独立部署。两边不合并。

hf-quest 的 42 课在新地图里的定位是「工具线：模型使用与部署的具体操作」，对应 `inference` 和 `engineering` 两个领域。
