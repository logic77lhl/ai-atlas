跨设备同步

未配置。token 只存在这台电脑的浏览器里。
三步：① GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → 只勾 gist。② 粘 token → 点「创建新存档」拿到 Gist ID。 ③ 另一台电脑打开同一网址，粘同一个 token + Gist ID，点「立即双向同步」。
合并规则：每个概念按各自的修改时间取新，冲突不动数据。token 建议 90 天过期，公用电脑用完点「清除」。
